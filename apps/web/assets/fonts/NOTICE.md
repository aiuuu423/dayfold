# Dayfold Hand Web Font

The `Dayfold Hand` CSS family uses the Regular weight from LXGW WenKai Lite,
packaged as Unicode-range WOFF2 subsets by `lxgw-wenkai-lite-webfont` 1.7.0.

- Upstream font: https://github.com/lxgw/LxgwWenKai-Lite
- Webfont package: https://www.npmjs.com/package/lxgw-wenkai-lite-webfont
- License: SIL Open Font License 1.1

The complete license text is stored in `OFL.txt`.
