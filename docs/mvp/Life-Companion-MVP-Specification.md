# Life Companion 记忆优先型 MVP 设计

版本：v1.8  
日期：2026-09-11  
产品形态：公开上线的响应式 Web  
开发资源：单人开发，AI 辅助  
计划周期：10 周

## 产品决策

首版采用方案 A，只验证一条核心路径：

> 用户愿意持续记录，并因 AI 能准确记住、自然调用和允许纠正而感到产品越来越懂自己。

完整 Timeline、复杂 Themes、周报与月报、高级记忆冲突处理、主动陪伴、PWA 和原生 App 不进入首版。公开上线所需的数据隔离、记忆控制、账户删除、服务失败兜底、监控和备份不得削减。

## 核心闭环

1. 用户记录一件事或发起对话。
2. 系统先保存原始内容，再请求 AI 回复。
3. 后台判断内容是否值得形成记忆。
4. 未来对话检索少量相关、有效且属于当前用户的记忆。
5. 用户可以查看来源、修改、删除或关闭记忆。
6. 系统只基于多条可追溯记录生成基础成长回顾。

## 视觉方向

视觉命题：

> 像一本被长期使用的私人生活册：轻、静、自然，有足够留白，也保留真实生活留下的痕迹。

关键词为克制、轻盈、生活感、年轻、留白、自然、精致和安静。界面首先呈现生活、记录与时间，AI 能力退到后台，不把模型、数据或技术能力作为视觉主角。

视觉采用 Grug 式整屏纸张。各页面可以使用不同的平涂纸张颜色，但字体、线稿、内容位置、底部导航和交互反馈必须保持一致。不再采用点状外框、内层白卡或装饰阴影。

| 页面 | 纸张颜色 | 主要文字 | 次要文字 |
|---|---|---|---|
| Today | `#C7E8F8` 奶蓝 | `#17191B` | `#526774` |
| Chat | `#FFFFFF` 白色 | `#17191B` | `#526774` |
| Memory | `#CDEFE2` 薄荷绿 | `#173129` | `#4B6A60` |
| Growth | `#0D5145` 深森林绿 | `#F1FBF6` | `#BED8CF` |
| Me | `#A9DDF6` 天空蓝 | `#142832` | `#446979` |

- 通过字号、字重、留白和对齐建立层级，不依赖卡片堆叠。
- Today 像一页生活记录，输入区自然嵌入内容流，不使用巨大 CTA。
- Chat 减少气泡和边框，AI 回复优先以连续正文呈现。
- Growth 使用编辑排版、时间和文字建立节奏，不做分析仪表盘或图表墙。
- Me 使用自我简介式连续排版，不使用账户中心列表或多列卡片矩阵。
- 控件以 8px 圆角为主，大容器最多 12px。
- 常规页面不用阴影，只在浮层、菜单和拖浮状态中轻量使用。
- 图像优先使用真实生活摄影、日常物件和自然光，不使用 AI 机器人插画。
- 动效使用短促淡入、轻微位移和内容展开，避免弹跳、粒子、霓虹和持续装饰动画。
- 每个首屏只保留一幅原创细线手绘图，位置居中，周围保留大量未填充空间。
- 字体采用 Grug 式手写排版。中文优先 `HanziPen SC / HanziPen TC`，英文优先 `Bradley Hand`，系统不可用时回退至 `PingFang SC`。标题使用 28–30px、轻字重、自然字距和短行宽；正文使用 16px 与约 1.65 行高。不使用方正楷体、系统楷体或微软雅黑。
- 日期、时间、类型、状态等不同字段不得使用中点拼接。字段应分行、分列或通过留白建立关系。

禁止 SaaS dashboard 感、过度科技感、紫蓝渐变、大面积玻璃拟态、过多卡片、AI 机器人插画、过度圆润的可爱风、高信息密度和过度阴影。

### Today 视觉锚点

Today 使用整屏奶蓝纸张。顶部只保留 `today.` 和日期，中央放置一幅原创细线图，记录问题与输入位于页面下半区。记录、时间和操作直接存在于背景上，不使用内容卡片；保存动作使用细线椭圆中的箭头或键盘快捷键。

### Chat 视觉锚点

Chat 使用整屏白色纸张，不采用左右彩色气泡。顶部是日期，中央是一幅原创细线图，对话位于页面下半区。用户内容和回应只通过角色小标记与留白区分，不使用侧线和容器。调用历史信息时，相关正文下方只显示“来自某次记录”的脚注；点击后才展示来源、日期、原始记录和 Memory 类型。

### Memory 视觉

Memory 使用手写索引式详情页。顶部只显示 `memory.` 和记忆数量，中央为原创细线图，页面下半区按“类型、内容、来源摘要”连续排列。置信度、状态和技术字段默认隐藏；点击单条记忆后，在原位置展开来源、日期、编辑与删除能力。

Memory 默认展示最近更新且仍然有效的记忆。用户点击“查看来源”后，来源区域在当前记忆下方展开，不改变页面滚动位置；再次点击原位收起。来源记录可继续进入原始日记或对话。编辑完成后，当前文字直接替换并显示保存反馈；删除采用二次确认，完成后该记忆退出当前列表和后续召回。来源已经删除或暂时不可用时，原位置显示说明，不跳转到空页面。

页面进入使用 220ms 透明度过渡，中央线稿在 560ms 内完成描边。来源详情使用 220ms 高度展开、180ms 透明度与 4px 纵向位移；关闭时反向执行。按钮按下只降低透明度并轻微缩放，不使用弹跳或涟漪。

### Growth 视觉

Growth 使用个人年鉴式详情页。时间范围分行呈现，中央为生长主题线稿，页面下半区只保留一段有依据的成长叙述和“查看依据”。不使用主题卡片、分数、百分比或图表。

用户点击“查看四条依据”后，四条来源摘要在当前叙述下方展开。每条依据显示日期和一行原文摘要，点击后进入对应日记或对话；返回时保留 Growth 的展开状态和滚动位置。用户标记“不准确”后，该段回顾停止作为当前结论展示，并进入待重新生成状态。记录不足时不显示操作按钮，只显示“还在慢慢积累”。

深森林绿纸张以 220ms 淡入，不做从浅色到深色的闪烁渐变。线稿描边时间为 560ms，叙述分三段以 35ms 间隔依次出现。依据区域使用 220ms 高度展开和 180ms 淡入；回到页面时不重复播放全部入场动画。

### Me 视觉

Me 使用自我简介式详情页。顶部显示 `me.` 和日期，中央为人物线稿，页面下半区依次呈现当前状态、兴趣词、记录数量、记忆数量及设置入口。账户与数据管理继续放在页面末尾。

“生活记录”和“被记住的事”都是页面入口。点击生活记录进入 Today 的历史状态，点击被记住的事进入 Memory；返回时保留 Me 的阅读位置。兴趣词只作为内容展示，不使用胶囊或标签交互。设置、隐私和数据管理使用普通文字链接，危险操作只有进入对应设置页后才出现。

数字入口按下使用 120ms 透明度变化和 `0.97` 轻微缩放。页面切换使用 220ms 纸张淡入，人物线稿在 560ms 内完成描边。设置链接只使用下划线变化，不进行位移或放大。

Today、Chat、Memory、Growth 和 Me 共用整屏纸张、手写字体、中央线稿、大量留白和低存在感底部导航，不改变原有功能、路径或 Memory 产品逻辑。

### 共用动效规则

- 页面切换：新纸张以 220ms 淡入，内容从下方 6px 回到原位；不使用横向推页、缩放舞台或背景模糊。
- 线稿出现：路径使用 `cubic-bezier(.22,.7,.2,1)` 在 560ms 内完成描边，每次主动进入新页面时播放一次。
- 内容顺序：页首信息、线稿、标题、正文和操作按 35ms 间隔出现，底部导航不参与入场动画。
- 展开收起：来源与依据在原位置展开，最长 220ms，不打开浮层，不改变页面主背景。
- 操作反馈：普通按钮使用透明度变化；需要强调按压时最多缩放至 `0.97`，禁止弹跳、发光和粒子效果。
- 减少动态效果：系统开启减少动态效果后，取消描边、位移和缩放，只保留即时显示与隐藏。
- 返回恢复：从来源记录返回时恢复上一页的滚动位置、展开项和纸张颜色，不重新播放完整入场动画。

## 功能规则

### Today

用户可以直接输入文本，不需要先选择情绪、主题或模板。保存动作先持久化原始内容，再创建 AI 和记忆后台任务。用户明确点击“继续聊聊”后才进入 Chat。编辑记录会触发相关记忆重新检查；删除记录会触发派生记忆和成长回顾的失效检查。

### Chat

系统组装当前会话、相关记忆和用户当前状态后再调用模型，不发送完整历史。记忆引用默认折叠，用户可以主动查看来源。模型超时、限流和安全拦截必须返回明确状态；重试不得重复保存用户消息或产生重复记忆。

### Memory

每条记忆保存类型、内容、置信度、状态、来源和更新时间。低置信度内容进入 Candidate，不参与正常召回。用户修改后的内容视为用户确认，自动任务不能无提示覆盖。删除或关闭的记忆必须立即退出检索。

### Growth

首版只展示近期主题和基础回顾。只有存在足够数量、跨越一定时间且来源可追溯的记录时才生成回顾；数据不足时显示“正在积累”。每条回顾必须能返回原始日记或对话。

### Me 与设置

Me 汇总用户主动填写的信息、记忆入口和数据管理能力。设置按账户、AI、记忆、隐私和数据分组。关闭记忆、清空记忆、删除全部内容和注销账户必须分别说明影响范围。

## 记忆模型

首版保留三类记忆：

| 类型 | 内容 | 进入条件 |
|---|---|---|
| 事件 | 用户经历过的重要事情 | 明确发生，具有时间信息或重要度 |
| 兴趣 | 反复出现或主动确认的偏好 | 多次表达或用户主动填写 |
| 目标 | 用户明确希望推进的事情 | 具有真实意图，不是随口假设 |

记忆状态包括：

| 状态 | 含义 | 参与召回 |
|---|---|---|
| Candidate | 已识别但置信度不足 | 否 |
| Active | 达到条件或被用户确认 | 是 |
| Updated | 被新信息或用户修改替代 | 只使用最新版 |
| Archived | 历史信息，不代表当前状态 | 默认否 |
| Deleted | 用户删除或来源失效 | 否 |

## 安全与隐私

- 所有查询绑定当前用户身份，跨用户读取、修改和召回必须为 0。
- 原始日记、聊天、记忆和成长回顾均视为私人数据。
- 日志不记录完整私人内容和模型密钥。
- 第三方模型只接收生成当前回复所需的最小上下文。
- 用户可以撤回记忆授权、清空记忆、删除内容和注销账户。
- 注销后停止后台任务，不能重新生成派生内容。
- AI 不进行医疗诊断，不使用制造依赖的表达。
- 高风险表达使用安全兜底和求助信息，不以脆弱状态提高留存。

## 开发优先级

1. `S0`：范围、页面、数据模型、删除链路和发布标准
2. `S1`：工程基础、账户、权限、日志和备份
3. `S2`：Today、Chat 和原始内容可靠存储
4. `S3`：Memory 提取、召回、来源与纠正
5. `S4`：基础 Growth、Me 和设置
6. `S5`：安全、性能、测试、灰度与上线

## 发布标准

- 用户 A 无法读取、修改或召回用户 B 的任何数据。
- 被删除或关闭的记忆不再进入模型上下文。
- 每条有效记忆能够查看来源并允许纠正。
- 模型、网络和异步任务失败不丢失原始内容。
- 账户注销会删除原始与派生数据，并停止后台任务。
- 数据库备份恢复经过实际验证。
- 关键移动端页面和输入流程可正常使用。
- 危险表达样例经过人工检查，AI 不诊断、不说教、不制造依赖。

## 观察指标

- 7 天与 30 天持续记录率
- 用户对记忆准确性的主观评价
- 记忆召回是否自然、相关且不过度
- 记忆修改、删除和“不准确”反馈比例
- 使用一段时间后，用户是否认为产品价值增加

指标仅用于定义上线后的观察方式，不代表已有结果，也不预设未经验证的目标值。
