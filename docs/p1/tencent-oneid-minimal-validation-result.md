# Tencent OneID 最小账户验证结果

状态：成本阻断，停止验证  
日期：2026-09-21  
当前阶段：P1 Closeout  
数据范围：腾讯云控制台与虚构测试计划，不含 Dayfold 业务数据

## 结论

Tencent OneID 不适合作为 Dayfold P1 / P2 首版 Managed Auth。

当前腾讯云账户可以登录 Tencent OneID 控制台，但没有已开通实例。用户管理、应用管理和资源用量页面都显示购买入口；创建测试应用和虚构用户前必须购买高级版。

购买页在本次验证中显示：

```text
高级版：120000 元 / 年
后付费开通冻结金额：0.02 元
后付费用量：0.02 元 / MAU，按月结算
自动续费：高级版到期后自动续费 1 年
```

该成本远超 Dayfold 当前 P1 / MVP 验证预算。验证在购买前停止，没有提交订单、冻结余额、创建实例或产生费用。

## 地域判断

本次验证不能确认 Tencent OneID 公有云身份目录、审计日志和备份的实际存储地域。

购买页没有提供地域选择。产品支持私有化部署不等于公有云数据可以固定在腾讯云上海，因此不得把“与腾讯云同一供应商”写成“与 Dayfold API 和数据库同地域”。

地域状态保持：

```text
UNKNOWN
```

该项不是测试失败，而是产品在未购买状态下没有提供足够证据。

## 登录流程判断

登录流程没有执行。原因是创建用户目录和应用需要先购买高级版，而不是技术错误。

不能根据产品文档推断以下链路已经通过：

```text
注册
  ↓
邮箱验证
  ↓
OIDC Authorization Code + PKCE
  ↓
FastAPI Token 验证
  ↓
internal user_id 映射
```

上述流程只有在可控成本的测试租户中实际完成后，才能标记为通过。

## 决策

Dayfold 停止 Tencent OneID 最小账户验证，不购买高级版。

Managed Auth 候选顺序调整为：

```text
Primary validation candidate: Authing
Fallback: self-hosted Logto on Tencent Cloud Shanghai
Rejected for P1 / MVP: Tencent OneID
```

Tencent OneID 只在以下情况重新评估：

- 腾讯云提供适合个人开发者的免费试用。
- 年度固定成本显著降低。
- 能在购买前明确身份数据地域。
- Dayfold 进入需要企业级 CIAM 能力的阶段。

## 安全与隐私

本次验证：

- 没有输入或保存虚构用户资料。
- 没有创建真实或测试身份。
- 没有读取 AccessKey。
- 没有在文档中记录腾讯云账号、手机号或邮箱。
- 没有连接 Journal、Chat、Memory、Growth 或数据库。
- 没有提交购买、开通后付费或开启自动续费。
